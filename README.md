# 💱 Exchange Rates Bot

Telegram-бот для получения актуальных курсов валют (USD, EUR, CNY) к рублю. Данные запрашиваются с API Центрального банка России, парсятся и кэшируются для быстрого ответа.

## 🚀 Возможности

- **Курсы валют по команде** — мгновенное получение курса доллара, евро и юаня
- **Автоматическое обновление** — кэш сбрасывается ежедневно в полночь, пользователь всегда получает актуальные данные на текущую дату
- **Устойчивость к сбоям** — при недоступности API ЦБ бот отдаёт понятное сообщение, а не падает с ошибкой
- **Логирование** — HTTP-запросы и операции с кэшем логируются для отладки

## 🛠 Стек технологий

- Java 17
- Spring Boot
- Spring Cache
- Spring Scheduling
- Telegram Bots API
- OkHttp
- XPath

## 📋 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и список доступных команд |
| `/usd` | Курс доллара США |
| `/eur` | Курс евро |
| `/cny` | Курс китайского юаня |
| `/help` | Справка по боту |

## 🔄 Как это работает

1. Пользователь отправляет команду (например, `/usd`)
2. Бот проверяет наличие закэшированного значения
3. Если данных в кэше нет — `CbrClient` через `OkHttp` запрашивает XML с курсами у API ЦБ РФ
4. Парсер на **XPath** извлекает значение нужной валюты по её ID (USD: R01235, EUR: R01239, CNY: R01375)
5. Результат сохраняется в кэш и возвращается пользователю с текущей датой
6. Каждую полночь Cron-задача `CacheInvalidationInvoker` очищает кэш, чтобы утром данные были актуальными

## 🗂 Структура проекта

| Компонент | Назначение |
|---|---|
| `CurrencyBot` | Обработка команд Telegram, отправка ответов |
| `CbrClient` | HTTP-клиент для запроса XML с курсами ЦБ |
| `CurrencyBotServiceImpl` | Бизнес-логика: кэширование, вызов клиента, парсинг |
| `CacheInvalidationInvoker` | Плановая очистка кэша по Cron |
| `ServiceException` | Кастомное исключение для ошибок сервисного слоя |

## ⚙️ Кэширование

Настроено через аннотации Spring Cache:

- `@Cacheable` — результат метода сохраняется в кэш с ключами `usd`, `eur`, `cny`
- `@CacheEvict` — принудительная очистка кэша по расписанию
- `unless` — кэш не сохраняется, если результат `null` или пустой
